# Documentation

## For Users

### The Spaced Repetition Algorithm

To create the best experience for you, Vocabulaire uses the [Free Spaced Repetition Scheduler (FSRS)](https://github.com/open-spaced-repetition/free-spaced-repetition-scheduler).

FSRS is based on three variables: `difficulty`, `stability` and `retrievability`. These are updated during review by applying a rating (`easy`, `good`, `hard`, `again`).

- The `difficulty` refers to the rating you give a vocabulary and affects `retrievability` and `stability`.
- A vocabulary with higher `stability` stays longer in memory than one with lower `stability`.
- The lower the `retrievability`, the higher the chance the vocabulary will be forgotten.

See [this technical explanation of FSRS](https://expertium.github.io/Algorithm.html#s-stability) for more details.

### Audio Support

When learning languages, speaking and listening matter. That's why Vocabulaire supports language recording — if you forget a pronunciation later, you can play it back.

### Common Tasks

To create the autogenerated Hive classes, run:

```
dart run build_runner build --delete-conflicting-outputs
```

Deploy icons in `/assets` with:

```
dart run icons_launcher:generate
```

Then clear the build cache:

```
flutter clean
rm -rf build/macos
flutter pub get
```
